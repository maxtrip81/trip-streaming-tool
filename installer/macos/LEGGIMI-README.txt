IT  Trascina "TRIP streaming tool" nella cartella Applicazioni. Al primo avvio scegli la lingua
    (Italiano / English); potrai cambiarla da Impostazioni → Interfaccia. Se macOS blocca l'apertura,
    fai clic destro sull'app → Apri. Concedi l'accesso al microfono quando richiesto.
    Per trasmettere l'audio di altre app installa BlackHole (https://existential.audio/blackhole/).

EN  Drag "TRIP streaming tool" to the Applications folder. On first launch choose the language
    (Italiano / English); you can change it in Settings → Interface. If macOS blocks it,
    right-click the app → Open. Allow microphone access when asked.
    To broadcast audio from other apps install BlackHole (https://existential.audio/blackhole/).
